# Portfolio — 3D & Design Systems

Локальный портфолио-сайт на React + Vite + Tailwind CSS.

---

## Запуск локального сервера

Node.js устанавливается отдельно на каждом компьютере. В репозитории хранятся только `package.json` и `package-lock.json`, а папка `node_modules` создаётся локально.

После клонирования проекта открой терминал в его папке и один раз выполни:

```bash
npm install
```

Для запуска сайта:

```bash
npm run dev
```

Эти команды одинаковы на macOS и Windows. Если PowerShell на Windows не принимает команду `npm`, используй `npm.cmd`.

Сервер запустится и выведет URL, например:

```
Local: http://127.0.0.1:5173/
```

Если порт занят, Vite автоматически возьмёт другой:

```
Local: http://127.0.0.1:5174/
```

**Главное правило:** если не работает или `ERR_CONNECTION_REFUSED` — проверь, что Vite запущен и используй тот URL, который он реально вывел.

## Работа с проектами

### Структура одного проекта

```
public/projects/{id}/
  cover.jpg          ← обложка карточки и раскрытого проекта
  content.md         ← текст, картинки, галерея
  process.jpg        ← картинка для markdown
  result-1.jpg
  result-2.jpg
  ...
```

### Добавить новый проект

1. Создай папку `public/projects/{id}/`
2. Положи туда `cover.jpg` и нужные картинки
3. Создай `content.md` с frontmatter-шапкой (см. ниже)
4. Добавь проект в `src/lib/portfolioData.ts` — достаточно одного id:

```ts
{
  type: 'project',
  id: '3d-1',
  category: '3d',            // необязательно — есть в frontmatter
}
```

Заголовок, обложка, год и категория подтягиваются из `content.md` автоматически
(путь к файлу — по соглашению `/projects/{id}/content.md`).

### Frontmatter (шапка content.md)

```markdown
---
title: Название проекта
year: 2024
category: 3d
cover: img-cover.png
---

# Название проекта
```

| Поле | Необязательно | Fallback |
|------|---------------|----------|
| `title` | да | первый `# Заголовок` в файле |
| `year` | да | бейдж с годом на карточке не показывается; поле уйдёт в фильтр по годам |
| `category` | да | категория из `portfolioData.ts`; значения: `2d` / `3d` / `design-system` |
| `cover` | да | первая картинка `![]()` в файле |

`category` нужна только для фильтра — на самой карточке не отображается.
Сам фильтр живёт в шапке сайта (на десктопе; на мобильном — в меню).

`cover` можно писать относительно папки проекта (`img-cover.png`),
абсолютно (`/projects/3d-1/img-cover.png`) или ссылкой (`https://...`).

### Markdown-контент (content.md)

```markdown
# Название проекта

## О проекте

Краткое описание проекта.

## Процесс

![Подпись к картинке](/projects/3d-1/process.jpg)

## Результат

![](/projects/3d-1/result-1.jpg)
![](/projects/3d-1/result-2.jpg)

---

### Инструменты

- Blender
- Geometry Nodes
- Cycles

> Цитата или важная заметка
```

Поддерживаемые элементы:

| Markdown | Результат |
|----------|-----------|
| `# Заголовок` | Заголовок проекта |
| `## Заголовок` | Заголовок секции |
| Обычный текст | Абзац |
| `![подпись](url)` | Картинка с подписью |
| Несколько `![]()` подряд | Галерея (сетка 2–3 колонки) |
| `- пункт` | Список |
| `> цитата` | Блок-цитата |
| `---` | Разделитель |
| `**жирный**` | Жирный текст |

## Разрешения изображений

### Обложки карточек (`cover.jpg`)

Обложка занимает всю карточку (`object-cover`), каждая третья — на всю ширину.
Рекомендуемый размер для Retina: **1200–1500 px** по ширине.

Минимум: **600 px** по ширине.

### Картинки внутри markdown (галерея, процесс)

- **Ширина: 1000–1200 px** покрывает большинство экранов
- Рекомендуемый формат: **WebP** или **JPG 80–85% качества**
- Размер файла: старайся держать до **200 KB** для обложек и **150 KB** для галереи

### Cover в раскрытом проекте

То же изображение, что и обложка, растягивается на всю ширину. Для 21:9 соотношения:

- **1920 × 823 px** — обычный экран
- **2400 × 1030 px** — для Retina / 4K

### Сжатие изображений

Можно использовать:

- **Squoosh** — https://squoosh.app
- **TinyPNG** — https://tinypng.com
- **ImageOptim** (macOS)
- **Photoshop** — Export → Save for Web

## Настройка внешнего вида карточки

В `portfolioData.ts` можно задать кастомные цвета:

```ts
borderColor: '#3b82f6',   // цвет рамки
bgColor: '#1a1a2e',       // цвет фона (если нет картинки)
```

Если не заданы — используются токены по умолчанию.

---

## Темы

Переключатель тем находится в правом верхнем углу хедера. Темы управляются через CSS-переменные в `src/index.css`. Все цвета, отступы, скругления и толщины бордеров — в одном месте.

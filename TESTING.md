# Локальное тестирование

## Автоматические проверки

```bash
npm run lint
npx tsc --noEmit
npm run build
npm run preview
```

## Анимации

- [ ] При загрузке страницы Hero-подзаголовок, заголовок и кнопки появляются плавно сверху вниз
- [ ] Секции `About`, `Projects`, `Skills`, `Contact` появляются при скролле
- [ ] Карточки проектов при наведении приподнимаются (`translateY(-8px)`), изображение слегка увеличивается
- [ ] Теги навыков и иконки появляются с stagger-анимацией
- [ ] Переход к секциям по якорным ссылкам плавный (`scroll-behavior: smooth`)
- [ ] При включённом `prefers-reduced-motion` анимации отключаются (проверить в DevTools → Rendering → Emulate CSS media feature prefers-reduced-motion)

## Адаптивность

- [ ] Header: на ширине < 768px появляется бургер-меню, на десктопе — горизонтальная навигация
- [ ] Мобильное меню открывается/закрывается, кнопка имеет aria-label и aria-expanded
- [ ] Сетка проектов: 1 колонка на мобильных, 2 на планшете, 3 на десктопе
- [ ] Сетка навыков: 1 колонка на мобильных, 2 на планшете, 4 на десктопе
- [ ] Текст Hero не обрезается на 320px
- [ ] Тач-таргеты кнопок и ссылок не меньше 44×44px
- [ ] Проверить портретную и ландшафтную ориентацию на мобильном устройстве

## Производительность и качество

- [ ] Lighthouse Performance ≥ 90
- [ ] Lighthouse Accessibility ≥ 90
- [ ] Lighthouse Best Practices ≥ 90
- [ ] Lighthouse SEO ≥ 90
- [ ] LCP изображение в Hero загружается без `loading="lazy"`
- [ ] Остальные изображения в карточках имеют `loading="lazy"`
- [ ] В консоли браузера нет ошибок
- [ ] Форма контактов: пустая форма показывает ошибку, заполненная — сообщение об успехе

## Кроссбраузерность

- [ ] Chrome / Edge
- [ ] Firefox
- [ ] Safari (если есть доступ)
